V7-1. ROOT CAUSE OF "The data you are trying to access has not been loaded yet. See Session.load"
----------------------------------------------------------------------------------------------------
Seen on: position_by_lap, gap_evolution, lap_scatter, stints, sector_heatmap, weather (all FastF1 charts).
Jolpica charts (grid, qualifying, pit stops) work, so the backend and network are fine. The error is FastF1's
DataNotLoadedError: a chart function touched session.laps, session.results or session.weather_data on a session
object whose load() had not finished, or had been called with those parts switched off.
position_by_lap appears twice, which points to a RACE: two concurrent requests, one starts the load, the other
receives the half-loaded object. Fix all of these:
1. A session is published to the shared registry ONLY after load() has returned successfully.
2. One lock per (year, round, session) so a second request waits for the first instead of reusing a raw object.
3. One fixed load profile for chart use: laps=True, telemetry=False, weather=True, messages=True. Telemetry loads use
   a separate registry key (telemetry=True) because the flags differ.
4. After load, verify access inside try/except and fail loudly with the real exception text.
5. Chart builders catch DataNotLoadedError and return status "not_ingested" (never a raw error string in the UI).
Reference code (backend/sources/fastf1_loader.py):
    import threading, logging, fastf1
    from fastf1.core import DataNotLoadedError
    log = logging.getLogger("loader")
    _REG, _LOCKS, _GUARD = {}, {}, threading.Lock()

    def _key(y, r, s, tel): return (int(y), int(r), s, bool(tel))

    def get_session(year, rnd, ident="R", telemetry=False):
        k = _key(year, rnd, ident, telemetry)
        if k in _REG: return _REG[k]
        with _GUARD: lock = _LOCKS.setdefault(k, threading.Lock())
        with lock:
            if k in _REG: return _REG[k]                       # another thread finished while we waited
            ses = fastf1.get_session(year, rnd, ident)
            ses.load(laps=True, telemetry=telemetry, weather=True, messages=True)
            try:
                _ = (ses.laps, ses.results, ses.weather_data)  # raises DataNotLoadedError if any part is missing
            except DataNotLoadedError as e:
                raise RuntimeError(f"load incomplete for {k}: {e}")
            if len(ses.laps) < 10: raise RuntimeError(f"lap data not published yet for {k}")
            _REG[k] = ses                                       # publish only when fully loaded
            return ses

    def peek(year, rnd, ident="R", telemetry=False):
        return _REG.get(_key(year, rnd, ident, telemetry))      # None until fully loaded, never a partial object
